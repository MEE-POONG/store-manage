# SabaiPOS — ระบบขายหน้าร้านและจัดการสต็อก (Retail & Minimart POS)

พัฒนาด้วย **Next.js (App Router) + TypeScript + Tailwind CSS + Lucide Icons** ออกแบบเน้น UI/UX สำหรับร้านค้าปลีกและมินิมาร์ท เก็บข้อมูลแบบ Persistence ใน `LocalStorage` พร้อมข้อมูลตัวอย่างเริ่มต้นครบชุด

## ฟีเจอร์หลัก (Features)

1. **หน้าขายหน้าร้าน (POS Cashier Terminal)** (`src/components/PosTerminalView.tsx`)
   - รองรับการยิง **บาร์โค้ด (Barcode 13 หลัก)** หรือพิมพ์รหัส **SKU** แล้วกด `Enter` เพื่อเพิ่มลงตะกร้าทันที
   - ปุ่ม **"ทดลองยิงบาร์โค้ด"** สำหรับจำลองการทำงานของเครื่องสแกนบาร์โค้ด
   - กรองสินค้าตามหมวดหมู่ หรือกรองเฉพาะ **สินค้าสต็อกต่ำ**
   - ระบบ **พักบิล (Hold Order)** และเรียกคืนบิลที่พักไว้
   - ระบบส่วนลดท้ายบิล (บาท หรือ `%`) และคำนวณ VAT 7%
   - รองรับการชำระเงินด้วย **เงินสด (พร้อมปุ่มธนบัตรด่วน & คำนวณเงินทอนอัตโนมัติ)**, **QR พร้อมเพย์**, **โอนเงิน**, และ **บัตรเครดิต**
   - ออกใบเสร็จรับเงินอย่างย่อ (`src/components/ReceiptModal.tsx`) พร้อมสั่งพิมพ์ (`window.print()`)

2. **ระบบคลังสินค้าและสต็อก (Inventory & Stock Management)** (`src/components/InventoryView.tsx`)
   - เพิ่ม/แก้ไข/ลบสินค้า กำหนดราคาทุน ราคาขาย หน่วยนับ และจุดแจ้งเตือนสต็อกต่ำ (`Min Stock`)
   - ปุ่มสุ่มสร้างรหัสบาร์โค้ดมาตรฐาน 13 หลัก (`885...`)
   - ระบบ **ปรับสต็อก**: รับสินค้าเข้า (`+`), ตัดสต็อกเสีย/ออก (`-`), หรือตั้งยอดคงเหลือใหม่ (`=`)
   - จัดการหมวดหมู่สินค้าพร้อมสีป้ายกำกับ
   - ประวัติความเคลื่อนไหวสต็อก (Stock Movement Logs) บันทึกทุกการขาย การรับของเข้า และการยกเลิกบิล

3. **ประวัติบิลขายและใบเสร็จ (Sales History)** (`src/components/SalesHistoryView.tsx`)
   - ค้นหาบิลย้อนหลังตามเลขที่ใบเสร็จ (`INV-...`), ชื่อสินค้า, หรือเบอร์โทรลูกค้า
   - ดูใบเสร็จย้อนหลังและสั่งพิมพ์ซ้ำได้
   - ระบบ **ยกเลิกบิล (Void Bill)** พร้อมคืนจำนวนสินค้ากลับเข้าสต็อกอัตโนมัติ

4. **แดชบอร์ดสรุปภาพรวม (Sales & Analytics Dashboard)** (`src/components/DashboardView.tsx`)
   - สรุปยอดขายสุทธิ, กำไรขั้นต้น (Gross Profit & Margin %), ยอดซื้อเฉลี่ยต่อบิล
   - อันดับสินค้าขายดี (Top Selling Products) และสัดส่วนช่องทางการชำระเงิน
   - รายการแจ้งเตือนสินค้าใกล้หมด พร้อมปุ่ม **เติมสต็อกด่วน (+24)**

5. **ตั้งค่าร้านค้าและจัดการข้อมูล (Store Settings)** (`src/components/SettingsView.tsx`)
   - แก้ไขชื่อร้าน สาขา เลขประจำตัวผู้เสียภาษี เบอร์พร้อมเพย์ และอัตรา VAT
   - สำรองข้อมูลทั้งหมดเป็นไฟล์ `.json` (Export JSON) หรือรีเซ็ตกลับเป็นข้อมูลตัวอย่างเริ่มต้น

## เดโมระบบเช่าแพ็กเกจ (Plan Rental, Multi-tenant)

แอป Next.js ตัวเดียวแยกเว็บตาม hostname ผ่าน `src/middleware.ts`

| URL | หน้าที่ |
| --- | --- |
| `http://store-management.localhost:3000` | เว็บเช่าแพ็กเกจ: ราคา → สมัคร + ตั้งชื่อร้าน (slug) → ชำระเงิน |
| `http://store-management.localhost:3000/admin` | หลังบ้าน: ร้านทั้งหมด, คำสั่งซื้อ, webhook log, ปุ่มล้างข้อมูลเดโม |
| `http://<slug>.localhost:3000` | POS ของแต่ละร้าน (ต้องล็อกอินด้วยบัญชีเจ้าของ) |

ขั้นตอนเดโม
1. `npm install` แล้ว `npm run dev`
2. เปิด `http://store-management.localhost:3000` (Chrome/Edge/Firefox รู้จัก `*.localhost` อยู่แล้ว ไม่ต้องแก้ไฟล์ hosts)
3. เลือกแพ็กเกจ → กรอกชื่อร้านและ slug (เช็คชื่อซ้ำทันที) → กดไปหน้าชำระเงิน
4. ชำระด้วยบัตรทดสอบ `4242 4242 4242 4242` (ผ่าน) หรือ `4000 0000 0000 0002` (ถูกปฏิเสธ) หรือแท็บพร้อมเพย์
5. ระบบจำลอง gateway ยิง webhook (มีลายเซ็น HMAC) มาที่ `/api/webhooks/payment` → สร้างร้าน + บัญชีเจ้าของ → พาไปที่ `http://<slug>.localhost:3000` พร้อมล็อกอินให้อัตโนมัติ

หมายเหตุ
- ระบบชำระเงินเป็น **mock** ทั้งหมด (`src/lib/server/payments.ts`) เมื่อต่อของจริงให้แทนที่การสร้าง charge ด้วย Omise/Stripe และใช้การตรวจลายเซ็นของผู้ให้บริการ
- ข้อมูลระบบเช่าเก็บที่ `data/db.json` (ไม่ถูก commit) โครงสร้าง tenants / users / orders / webhookEvents / sessions พร้อมย้ายไป PostgreSQL
- ข้อมูล POS ของแต่ละร้านยังอยู่ใน localStorage ซึ่งแยกตาม subdomain อยู่แล้ว (ฝั่ง backend POS เป็นงานของอีกทีม)
- ค่าตั้งค่าดูได้ที่ `.env.example`
